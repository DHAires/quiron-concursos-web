**✅ O QUE O USUÁRIO VÊ:**

1. **Banner** → Sempre no rodapé (exceto no jogo)
2. **Contador ⚡** → Sempre no header
3. **Botão ⚡+** → Sempre disponível para ganhar energia
4. **Intercalar Premiado** → Surpresa a cada 5 questões (+2 ⚡)
5. **Intersticial** → Após completar atividades
6. **Modal Sem Energia** → Incentivo para assistir anúncio

- Banner: **Receita passiva constante**
- Intersticial: **Receita em transições**
- Premiado: **Receita alta + engajamento**
- Intercalar: **Retenção + receita**
