## 🎮 INTEGRAÇÃO COM O GAME ÉPICO

### **Como o Banco Funciona no Game:**

1. **Seleção de Área:** O jogador escolhe uma das 4 áreas temáticas
2. **Seleção de Matéria:** Escolhe uma das matérias dentro da área
3. **Geração de Questões:** O game sorteia questões daquela matéria
4. **Formato de Carta:** Cada questão aparece em uma carta 3D interativa
5. **Resposta:** Jogador escolhe CERTO ou ERRADO
6. **Feedback Imediato:** Mostra explicação detalhada
7. **Pontuação:** Acertos somam pontos para o ranking

### **Sistema de Energia:**
- Cada questão no Game Épico consome 1 energia
- Usuários Freemium ganham energia preenchendo perfil
- Usuários Premium têm energia ilimitada

## 💡 DICAS PARA DESENVOLVEDORES

### **Adicionar Nova Questão:**
```typescript
{
  id: 'const_051',
  area: 'juridica',
  subject: 'Direito Constitucional',
  question: 'Enunciado da questão aqui.',
  correctAnswer: true, // ou false
  explanation: 'Explicação detalhada aqui.',
  difficulty: 'facil' // ou 'medio' ou 'dificil'
}
```

### **Adicionar Nova Matéria:**
1. Criar array de questões em `/data/gameQuestions.ts`
2. Adicionar matéria em `gameAreas`
3. Atualizar `getSubjectQuestions()` em `/components/QuestionBankViewer.tsx`
4. Importar questões em `/components/EpicGame.tsx`

### **Testar Questões:**
1. Acessar "Banco de Questões" no menu
2. Selecionar área e matéria
3. Verificar contagem de questões
4. Testar questões aleatórias
5. Validar explicações
