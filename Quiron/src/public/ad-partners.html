🛡️ Parceiros de Anúncios e Dados

Transparência sobre como seus dados são processados

💡 Por que compartilhamos dados?

Para oferecer o Quiron Concursos gratuitamente, utilizamos parceiros de confiança que nos ajudam a:

  • Monetizar via anúncios relevantes
  • Melhorar o app através de análises de uso
  • Fornecer funcionalidades (notificações, sincronização)

🤝 Nossos Parceiros

🔷

Google AdMob

Principal parceiro de publicidade

📊 Dados Coletados:

  • ID de publicidade do dispositivo
  • Endereço IP (anonimizado)
  • Informações do dispositivo
  • Dados de localização aproximada
  • Interações com anúncios

🎯 Finalidades:

  • Exibir anúncios relevantes aos seus interesses
  • Medir performance de campanhas
  • Prevenir fraudes publicitárias
Política de Privacidade Desativar Personalização
📊

Google Analytics

Análise de uso do aplicativo

📊 Dados Coletados:

  • Páginas visitadas e tempo de uso
  • Eventos e interações no app
  • Dispositivo e sistema operacional
  • Dados demográficos agregados

🎯 Finalidades:

  • Entender comportamento dos usuários
  • Identificar bugs e problemas
  • Otimizar funcionalidades
Política de Privacidade Opt-out
🔥

Firebase

Analytics, notificações e crash reporting

📊 Dados Coletados:

  • Identificador de instalação (FID)
  • Dados de crashes e erros
  • Tokens de notificação push
  • Eventos personalizados de uso

🎯 Finalidades:

  • Enviar notificações push
  • Detectar e corrigir crashes
  • Melhorar estabilidade do app
Política de Privacidade
⚡

Supabase (AWS)

Infraestrutura de backend e banco de dados

📊 Dados Armazenados:

  • Dados de cadastro (nome, e-mail, CPF)
  • Progresso de estudos
  • Configurações da conta
  • Conteúdo gerado pelo usuário

🎯 Finalidades:

  • Armazenar dados da conta com segurança
  • Sincronizar progresso entre dispositivos
  • Autenticação e backup

🌍 Transferência Internacional

Alguns parceiros armazenam dados em servidores fora do Brasil:

  • 🇺🇸 Estados Unidos: Google (AdMob, Analytics, Firebase), Stripe
  • 🇪🇺 União Europeia: Supabase (AWS - servidores podem variar)
  • 🇧🇷 Brasil: MercadoPago, dados locais

🔒 Proteções Legais: Todos os parceiros utilizam cláusulas contratuais padrão (SCC), certificações ISO 27001 e estão em conformidade com GDPR/LGPD.

⚙️ Como Controlar Seus Dados

🎯 Desativar Anúncios Personalizados

Android:

  1. Configurações → Google → Anúncios
  2. Ative "Desativar personalização de anúncios"
  3. Ou redefina o ID de publicidade

iOS:

  1. Ajustes → Privacidade → Rastreamento
  2. Desative "Permitir Solicitações de Rastreamento"

Online:

Google Ads Settings

📊 Desativar Analytics

No Quiron Concursos:

  1. Menu → Perfil → Configuração
  2. Privacidade → Coleta de Dados
  3. Desative "Compartilhar dados analíticos"

🗑️ Excluir Dados

Para remover todos os seus dados:

  1. Menu → Perfil → Configuração
  2. Privacidade → Excluir Conta
  3. Ou envie e-mail: privacidade@quironconcursos.com.br

⚠️ A exclusão é permanente e não pode ser desfeita. Dados serão removidos em até 30 dias.

✨ Versão Premium - Mais Privacidade

Ao assinar o Quiron Premium, você reduz significativamente o compartilhamento de dados:

  • ✅ Sem anúncios: Google AdMob não coleta mais dados de publicidade
  • ✅ Analytics básico: Apenas dados essenciais de performance
  • ✅ Menos compartilhamento: Redução de terceiros envolvidos
