## 🚀 COMO PUBLICAR (RESUMO RÁPIDO)

### Android (Google Play Store)

```bash
# 1. Tornar script executável
chmod +x scripts/build-android.sh

# 2. Executar build
./scripts/build-android.sh

# 3. Escolher AAB (opção 1)
# 4. Upload em: https://play.google.com/console
```

**Tempo:** ~2-3 horas + 1-3 dias aprovação

### iOS (Apple App Store)

```bash
# 1. Tornar script executável (apenas macOS)
chmod +x scripts/build-ios.sh

# 2. Executar build
./scripts/build-ios.sh

# 3. Escolher opção desejada
# 4. Upload em: https://appstoreconnect.apple.com
```

**Tempo:** ~3-4 horas + 1-7 dias aprovação

## 🎯 PRÓXIMOS PASSOS (EM ORDEM)

### Passo 1: Contas e Certificados

```bash
# 1. Criar conta Google Play Console
https://play.google.com/console/signup
Custo: $25 USD

# 2. Criar conta Apple Developer
https://developer.apple.com/programs/enroll/
Custo: $99 USD/ano

# 3. Gerar keystore Android (uma vez)
keytool -genkeypair -v -storetype PKCS12 \
  -keystore android/keystore/quiron-release-key.keystore \
  -alias quiron-release -keyalg RSA -keysize 2048 \
  -validity 10000

# 4. Gerar certificados iOS (no Apple Developer Portal)
https://developer.apple.com/account/resources/certificates
```

### Passo 2: Preparar Assets

```bash
# 1. Criar ícone base (1024x1024)
# Ferramenta: Figma, Photoshop, etc.

# 2. Gerar todos os tamanhos automaticamente
npm run icons:generate

# 3. Capturar screenshots
# - Abrir app em dispositivos/emuladores
# - Capturar principais telas
# - Editar e otimizar

# 4. Criar feature graphic (Android)
# Dimensões: 1024 x 500
```

### Passo 3: Build Android

```bash
# Executar script automatizado
chmod +x scripts/build-android.sh
./scripts/build-android.sh

# Escolher opção 1 (AAB)
# Arquivo gerado em:
# android/app/build/outputs/bundle/release/app-release.aab
```

### Passo 4: Build iOS (macOS apenas)

```bash
# Executar script automatizado
chmod +x scripts/build-ios.sh
./scripts/build-ios.sh

# Escolher opção adequada
# Fazer upload via Xcode Organizer
```

### Passo 5: Upload Google Play

```
1. Acesse https://play.google.com/console
2. Crie novo app
3. Preencha ficha da loja
4. Upload AAB em "Versões → Produção"
5. Envie para revisão
6. Aguarde 1-3 dias
```

### Passo 6: Upload App Store

```
1. Acesse https://appstoreconnect.apple.com
2. Crie novo app
3. Preencha informações
4. Upload build via Xcode
5. Selecione build na versão
6. Envie para revisão
7. Aguarde 1-7 dias
```
